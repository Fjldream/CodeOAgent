# 未绑定客户端画面的采集点查询验收

2026 年 11 月 21 日，Center 与测试节点为 192.0.2.1。本机 M6 开发中心入口为 5179。使用类型 03 的普通账号完成了查询、原生二维编辑器操作和运行页面核对。对话链路另用真实 OpenCode、回环测试模型及真实 KF 权限复验，云模型自然语言质量留给独立验收。

## 客户怎么用

1. 在客户端工程打开「页面管理」，点页面名打开原生编辑器新标签，单选要显示数据的控件。
2. 打开「开发助手 → 工程工具 → 查采集点与变量映射」。可以留空先浏览，也可以输入准确点名。出现多个候选时输入设备名、数采工程名或工程标识，再点「查询」。
3. 按结果继续。查到源且客户端缺连接时，在「数据源管理」添加该源。已有连接且缺映射时，在「工程变量 → 快速添加」选择该连接和采集点。已有映射时，使用查到的客户端变量名配置控件。变量在快速添加时可能改过名称。
4. 回到原标签重新查询。结果分别展示数据源、客户端别名、变量、订阅配置，以及在支持的脚本写法中能否识别选中控件的显式读取。核对运行结果时，需再打开同一目标 App 的运行页面观察该控件。
5. 原账号可以在已有对话提问，例如「我已建好 ProbeTemp1121，当前控件如何绑定北侧 NorthRTD 的点？请先核对连接和映射。」助手的工具返回本轮匿名状态，引用的真实字段在本机展开。相关历史读取会重验依赖工程的权限。
