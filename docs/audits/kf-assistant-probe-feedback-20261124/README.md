# 业务口径校验候选版

冻结号 `2dadd7b42b96`，基于独立盲验版本 `5d3ea4247b32` 修订。开发回归 178/178，试点回归 51/51。此版待新题端到端验收，常规 M6 仍运行 `67089443fe25`。

确认清单在核对可写内存变量时提供同步赋值、异常和返回码的接口依据。模型设计异常输入时，必须使用可通过 JSON 传输的取值。解析失败会退回可操作的诊断。独立复核请求显式指定标准 JSON。相同合成输入可以分别设置正常写与显式写异常；只有脚本实际访问该变量且触发预定故障，故障样本才可通过。两个模型调用各自产生期望，复核调用只收到已确认的条款及合成条件。任一检查未通过都阻止候选交付。

自动执行的对象是已确认的请求式或周期性脚本。执行器覆盖本地内存和已模拟的 KC 读写，其他外部操作缺少模拟依据时会中止。每个样本单独运行；真实 App、进程间缓存、调度和其他四类计算脚本仍须分别取证。

后续验收应先核对独立复核返回的字段和逐项差异，然后验证原对话一次确认、两版完整正文和保存回读、正常与异常实机回包，以及新旧变量的写入次数。历史三次验收记录分别保留。
