# 工程引用、质量与脚本修订验收

**周期写回盲验未通过。** 冻结版 5f6b8a8bfb73 在独立库位题上提交了候选，但未能向开发人员交付可用正文。普通账号回读周期脚本数为 0，计算实例尚未挂接，无法核对真实写回。本次保留原 M6 试点。

## 已验能力

- 使用 eslint-scope 按 JavaScript 作用域定位每次实际引用。声明关键字支持 var、let 和 const，追踪使用前的单次初始化或独立赋值及其别名链。多个写入点、闭包改写、遮蔽参数和无法证明会执行的条件初始化会产生诊断。诊断标明行号、实参位置、原因和本轮允许的匿名引用。
- 对要求坏质量停写的纯 KIO 周期，模型可以随稿提供有权限的匿名输入和合成值。本机 QuickJS WebAssembly 环境仅模拟读写，不提供工程连接。按正常、逐一输入 Q=0、恢复 Q=192 执行连续周期，检查有没有调用写接口。合成测试能发现坏质量仍写、恢复后一直停写，并将问题交回修订。合成写入次数不能证明物理设备收到正确的值。
- 5f6b8a8bfb73 的 99 项测试通过，逐文件摘要与冻结副本一致。冻结后选取既有仓储工程中指定车型的可用空位标志，固定两个合格库位，保留任一为空即有空位的原规则。题源、条件及预期

## 现场证据

1. 在 192.0.2.1 用普通开发身份建立独立数采、实时源和计算工程。用普通账号监视两个输入，正常期质量均为 192，模拟器返回读故障时均为 0，解除故障后均恢复为 192。源时间随状态更新。
2. 首次测试的代理提前校验了模型参数，未能把原始提交交给产品。仅修正代理并用相同冻结版本、相同题目、新对话正式重测。
3. 正式测试取得 8 个 DeepSeek 请求回执，模型四次提交候选。质量样本和正文都使用了题面显示名，样本字段需要工程工具给出的匿名引用。MCP 在提交前拒绝参数，每次都返回笼统的权限或额度提示，服务端的模型历史也没有字段级诊断。最终对话显示“OpenCode 未返回完整答复”。
4. 现场未产生可保存的对话正文。测试工程回读 0 个周期脚本。质量的现场变化已经核实，坏质量期间计算 App 停写、恢复后写回正确值仍待真正的计算实例验证。现场、工具与对话回执

## 独立验收后的通用修订

冻结候选 6cb22159b4fb 将草稿参数送到服务端统一检查。测试样本与工程绑定在同一层核对，可以把错误字段和候选匿名引用、正文行号和改法一起交给模型。初稿语法有误也可收到具体诊断。取材结果按问题字符位置列出对应 ref，帮助模型定位匿名引用。

本地 OpenCode 重放了正式盲验的首份错误候选，随后以固定测试输入验证了坏质量误写会被退回，修订后的正文通过合成验证，并逐字出现在对话中。此项验证使用真实本地服务和工程权限、预录的模型动作。修订版尚待另一道新题的真实云端独立验收；原题没有用于调整业务生成模板。修订版冻结清单
