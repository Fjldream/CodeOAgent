# 周期脚本日历调度验收

冻结版 `364673ff7c40`。127 项通用回归通过后才创建现场测试工程。助手沿用当前普通账号的工程权限，脚本编辑器按 GUID 定位，周期脚本列表支持按分组和完整名称回读。日历核对由本机工具执行，本轮云端调用为零。

## 从配置读到执行时刻

- 开发态在「计算工程 → 脚本 → 周期性脚本 → 属性」保存启用状态、开始与结束时间、节点本地触发时刻，以及按日、星期、月、年的规则。月和年可指定日期或第几个星期几。分钟选择器步长为 1 分钟。
- 节点加载启用值为「是」的脚本，按进程本地日期计算日期条件，刷新宿主时钟约每 100 ms；日历轮询约每 500 ms。开始和结束边界均包含在有效期中。持续运行时取当日触发时刻与有效期起点的较晚者，到达后第一次满足条件的轮询执行；日内去重。延迟和实际执行失败还须分别取证。
- 当前源码在初始化时将已过触发时刻的规则写入当时时钟，影响当天补跑。进程停机、重启、当日状态和调度延迟都会改变实际次数。查询日期使用节点本地日，带时区的有效期换算采用目标日期的节点偏移。夏令时切换日的重复或缺失时刻需在对应节点核对。
- 原生日期函数按 1 到 7 日、8 到 14 日等分段算第几个星期几。编辑器周日为 7，节点取 0。末周在非二月从 25 日开始，二月阈值取决于年份能否被 4 整除；年度末周分支可以跨月份命中。开发态模型中数字字符串校验也可能拒绝末周索引 0。上述差异按源码和本地回归标注。
- 单元测试直接加载 Node 快照的日期判定函数，比较日、周、月、年规则在平年、闰年、大小月及周日的预期。另测边界、偏移未知、禁用、不完整配置、脚本选区和模型可见字段。源码路径及指纹已记录在 回执。
