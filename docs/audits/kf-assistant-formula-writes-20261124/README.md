# 独立公式的模拟赋值与现场验收

冻结版 `cc7201851d01` 通过 182 项开发回归和 55 项试点回归。参考程序能够对隔离的绑定调用 write(value)，执行器实际观察有序赋值、同值写入和显式故障；既有纯函数描述的写入回执继续校验。程序的输出与候选 JS 的模拟执行分开计算。上一题的两份真实模型原稿在本机通过全部 18 个条件，包括两条抛错。详见回放记录。

本轮冻结后从来源脚本对两种 MES 归档终态的判断派生独立题，初版合计两种状态，变更版按数量做差。原普通账号在原对话发起需求并确认一次。助手核对了正确的输入、输出和业务口径。三份参考稿在 input 与 InParam 之间多读了一层，实际合成入参是直接的业务对象。第一份还把函数体包在一个外层函数中；后两份去掉了外层函数，保留了错误的数据访问路径。

例：输入 {"states":[2,-1,0,1]}，根据已确认口径应回 {"count":2} 并成功写一次 2。公式当作缺参，实际回 {"count":null} 且写入零次。原对话明确显示输入、实际回包和实际写入。该版本尚未建立可信预期，回复没有给出正确数值 2。此处的 2 来自独立验收计算。未交付完整 JS，未发变更确认，未保存脚本或请求专用 App。原对话历史、正式清单及 M6 常规服务已核实。
