# 方案级总览

在任一已打开的客户端、数采、报警、数据源或计算工程中，打开开发助手，选定个人方案和对话，问“我们这个方案是做什么的？”。模型可以选择只读工具 inspect_solution_overview。工具返回本机可显示的证据和匿名状态。页面沿用已有的查询过程和分段排版。

**如何读回答**　工程段按保存的连接解释数据来源和消费端。数据源连到数采用工程标识，报警连接用平台源标识及名称；客户端和计算工程别名需要唯一对应平台源。页面变量、词典 IO 映射和本方案访问过的页面、脚本的显式读写单列。共享上游的其他工程保留为技术关联，方案归属待确认。一次查询按每类最多 8 个目录候选、近期来源和最多 12 个已访问对象展开。外部系统、运行时动态引用和未读工程可能超出此次结果。

**对话与清单**　工具只从本账号同一方案读取近期 160 条已完成的自由提问，在仍有权读取的来源中摘录最多 4 段与方案名、工程名或当前具体对象有关的需求陈述。来源同时包含提问和陈述时，单独摘取陈述。归属证据不足时保留空缺。清单只列开发人员已确认、当前仍有权读取的条目，显示版本。查询没有创建提议或确认清单的写入路径。

**查询过程**　“查找当前账号可读的关联工程”“追踪数据源、工程别名和变量映射”“核对方案中已访问对象的读写方向”“回看开发人员在方案对话中的原话”“读取开发人员已确认的方案清单”分别在对应工作开始与结束时发送事件。回看历史时仍需通过来源权限检查。
