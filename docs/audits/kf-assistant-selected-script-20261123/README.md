# 从当前编辑器解释计算脚本

M6 试点版本 `b91802d3d638`。普通开发人员双击脚本，点「询问此脚本」，在原对话提问。工具按工程、脚本类别、对象 GUID 和条件事件子页读回对应正文，再和提问时浏览器的指纹核对。条件事件分别解释进入、存在和离开。编辑文本有改动时，助手可接收本轮编辑稿，在本机校验指纹并区分当前正文与已保存的触发配置。浏览器无法提供指纹时，说明依据为已保存版本。

计算脚本宿主和配置菜单沿用 KF 开发态脚本编辑器、计算配置回读和日历解析。脚本由 Acorn 在本机解析，区分定义与调用、局部变量与宿主对象、读写顺序、条件分支、循环、返回、点位操作以及请求响应。模型按问题选择工具；此工具只返回宿主、解析状态和证据占位符给模型。实名解释由本机填入答复。普通账号的工程权限在读取和交付时校验。脚本按静态控制流解释，动态调用目标、未展开的外部函数及实际写入值仍需其他依据；复杂表达式保留 JS 原式，长脚本会标明部分展开。
