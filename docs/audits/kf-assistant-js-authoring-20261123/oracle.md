# 独立题来源与预期

冻结后选择安装包教程《3分钟完成业务计算数据到界面展示》3.3 节。原教程按设备、状态筛选历史行，按时间升序取首末时间，相减后以 d、h、m、s 输出所有非零分量。期间出现其他状态也取首末跨度。教程原有正文、时长样例和结果不进入模型请求。原件保留在本机安装目录。

本轮测试将关系库换为独立的 PostgreSQL，以合成表和毫秒时间戳控制输入。另约定查无匹配或查询失败时返回 NA，单条为零跨度、返回空串。增加周期缓存读口以独立观察调度结果。当前范围为计算服务及其数据源，未验客户端图表。

| 合成输入 | 独立预期 |
| --- | --- |
| A 的状态 0 最早 26216000、最晚 120000000 毫秒，中间另有重复、乱序、非零状态及其他设备 | 93784 秒，即 1d2h3m4s |
| A 仅一条符合记录 | 空字符串 |
| 只有其他设备或其他状态 | NA |
| 匹配时刻为 4000、124000 毫秒 | 2m |
| 独立模拟库停机，查询报错 | NA |

每组都须读实时请求及只读周期缓存，切换场景后等到下次调度重新读缓存。现场数据与预期单独保管，静态通过不能替代实例返回。若发现冻结能力缺陷，保留此次结果并另题验下版。
