# 对话轮次导航

聊天正文左缘按发言顺序显示刻度。一条刻度对应一轮可见提问。悬停或键盘聚焦可预览问题，点击将当前轮的提问定位到视口上沿，滚动正文会高亮当前轮。键盘上下键跳到相邻轮次，Home、End 跳到首末轮。离开底部回看时停止跟随新回复，回到底部或主动发送消息时恢复跟随。

新增纯前端组件复用已加载且当前账号可见的对话数据。单轮对话、方案清单和工具页无需显示导航。候选界面已用原普通账号、83 轮原对话验证鼠标预览与跳转、键盘导航和滚动联动。验收没有向模型发送提问。浏览器检查
