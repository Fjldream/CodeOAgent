## 停止生成的原因

模型首次批量查了 SQLQuery、SQLExec、endResponse、getCurrentTime、IsFinite、Round 等符号，其中 SQLExec 未登记。随后查了 sql 函数族、Round、周期宿主，又查了一次相同的 sql 函数族。工具计数达到上限后，准确符号 SQLExecute 的查询被拒。模型继续发出已从当前工具目录移除的查询；候选提交工具仍在目录中。接口资料、调用计数和本轮实际调用记录可以分别复核。

当前实现按调用次数计额，缓存命中也占用一次；查询结果只把最近一次及部分既往摘要供下一轮使用。独立于此预算限制，冻结版将 SQLExecute 列为已登记，尚无针对它的完整用法卡片。因此只调大次数也不能证明可用。后续开发应先解决重复查消费额度、已关闭工具请求的反馈，以及已登记写接口的调用约定，然后以宿主级回归和另一个未用题验证。只有当客户对话、工程正文和运行写回在同一冻结版全部对上，才更新 M6。
