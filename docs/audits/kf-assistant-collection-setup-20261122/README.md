# 数采工程中的设备与点配置

## 客户操作

| 手上的资料 | 在 KF 里操作 | 核对结果 |
| --- | --- | --- |
| 已有数采工程，尚未确定驱动 | 在「数采管理」选工程组，单击工程名。打开「开发助手 → 工程工具 → 设备与点配置」，配置项选「工程平台与驱动」。可填驱动名或设备系列关键词，点「查询」。 | 结果先给出该工程的系统与 CPU 平台，再列驱动名、系列、版本及类型。多个候选需与实际设备型号和支持的通信协议逐项核对。 |
| 需要建一个新点 | 在「数采设备 → 新建设备」打开驱动库，选定驱动，依厂家通信参数填写并保存。切到助手的「设备、寄存器与点」，填写完整设备名，点「查询」；然后填写寄存器名，再点「查询」。 | 第一遍看到设备的驱动、激活设置和寄存器列表。第二遍看到所选寄存器允许的数据类型。在「数采变量 → 新建」选择同一设备与寄存器，应能看到相同类型选项。 |
| 有点表，准备填写数采变量 | 按点表核对本测量项的寄存器、地址起算方式、编码与位宽。多字数据按厂家说明核对字序。填写寄存器类型、转换数据类型、读写类型及适用的换算字段，保存。 | 在工具中输入完整采集点名即可重读。对照点地址、两种类型、系数和偏差。启用线性换算时对照四个上下限。同名或设备归属冲突时核对点所属工程和设备。 |
| 点已保存，需要验证通信 | 在目标节点确认该工程的数采 App 已部署并运行。在同一数采工程的「工程工具」切到「读取实时点值」，点「查询」列出有权 App，选择准确实例、输入点名，再点「查询」。间隔至少一个采样周期重复。 | 核对每次的值、质量、源时间和读取时间。用已知模拟输入或仪表读数核对量纲和换算，检查第二次源时间前进。设备未激活或点只写时，先复核设备或选择可读取的测量点。 |

在同一工程的对话也可以直接问“这个点已保存，帮我核对寄存器类型和系数，下一步怎样验证通信？”助手按当前提问和有权工程读取字段，原始配置在本机展开。设备手册提供物理单位、倍率定义和地址基准；助手只根据这些资料指导填写具体值。
