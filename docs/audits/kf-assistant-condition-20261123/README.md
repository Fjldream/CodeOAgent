# KF 计算助手 · 条件事件脚本

冻结版 `7c7ec4dc2a02` 通过 106 项通用回归和普通账号的独立 App 盲验。开发界面和本机 M6 试点已更新。

## 生成与校验

在计算工程打开条件事件脚本，从“询问此脚本”提出业务需求。助手从当前账号可读的工程词典、数据源和点映射中选择变量。输出包括“数据项”条件表达式、“生效”设置、“存在时”的间隔与单位，以及能独立复制的进入、存在和离开三段 JavaScript。三段分别按无入参宿主检查语法、KC 接口及工程引用。表达式通过语法树验证和本机引用绑定。

本次支持以工程词典变量构造无副作用的比较、算术和布尔组合。使用直接数据源表达式、LIKE/NOTLIKE 或任意函数调用的条件需另行验证。未取得可核对的变量时应先确认映射。对 I/O 映射变量，输入中断可能保留词典旧值，业务需要失联退出时应另行设计并验证质量条件。

## 源码约定

“数据项”设置表达式，“存在时”页签设置周期。Center 记录 in、exist、out 三份正文。运行态加载启用的条件事件，以约 50 ms 为扫描间隔。条件首次严格为 true 执行进入，下一次扫描仍为 true 才启动保持计时器。持续为真时每满一个间隔调一次存在，严格为 false 时清除计时器并执行一次离开。再次为真可重新进入。回调的异步完成顺序还受耗时影响。直接数据源引用另有断连分支。编辑器列出 ms，当前节点代码给 ms 使用默认的 1000 倍乘数，助手只交付 s、min、hour，并限制在 Node 定时器可表示范围内。开发态编辑器 · 界面保存 · 节点调度
