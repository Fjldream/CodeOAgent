# 工程变量实名与脚本交付验收

冻结版 `6529e59fc5bc`。开发回归 169 项、试点回归 44 项全部通过。服务使用与脚本校验器一致的工程变量匿名引用处理需求和确认材料，清单在本机用可读工程词典还原。无消费者的局部映射会收到诊断。用上一个版本曾交付的实际 JS 回放，旧版接受的无用映射已被新版拒绝。

冻结后从已有的车型、颜色策略匹配函数派生一题。普通开发账号在原对话四轮完成初版和变更，分别只确认一次。两份 JS 已逐字回读并记录 KF 追加的末尾换行。两版需求清单正确显示工程实名。脱敏网关逐请求检查本场工程名、点名、变量名和凭据；验收所用合成问题到达网关时就已由服务投影为匿名引用。对照表、原历史与现场读数未发往供应商。

两版在同一专用计算 App 顺序测试，各 9 次。初版全部通过。变更后旧变量新增写入 0 次，新变量实际写入 6 次，预期 5 次。一条记录缺少颜色字段时，本应回 null 并停写，实测回 1 并多写一次。后续绝对计数跟着多一次。原对话的“沿用”条款已要求两字段均为字符串，生成工具传给模型的材料只有当前口径，遗漏了沿用条款。本版本未部署到 M6。
