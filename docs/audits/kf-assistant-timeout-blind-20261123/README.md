# MES 任务超时置位独立盲验

**冻结版 6cb22159b4fb 通过了本题的对话交付、工程保存、实例部署与设备写回验收。** 本机 M6 已切换，原普通账号可继续打开原对话，切换前后均为 13 轮，历史摘要相同。

## 题目与边界

先复核冻结副本与工作区的完整 SHA-256，再从已有仓储方案选择此前未用的 MES 任务超时分支。原规则根据任务起始时间算出已执行秒数，本次用两个模拟寄存器给出已执行秒数和任务状态。严格大于 75 秒且状态小于 5，或严格大于 150 秒时，周期写入整数 1。其他周期保持已有报警位。输入质量与恢复是本场附加验收项。预期值在模型调用前登记。题源摘要与预期

使用 192.0.2.1 上的普通开发账号、新对话、独立计算 App 和专用 Modbus 模拟器。一次预检发现旧公式工具的可选属性名包含模拟点名，脱敏代理在请求发出前将其拦截，该次真实供应商请求为零。正式验收在代理的旧公式工具说明中省略此可选属性；脚本工具、冻结包及试题均沿用原样。模型仅收到脱敏题、匿名引用、接口说明及本轮检查材料。
