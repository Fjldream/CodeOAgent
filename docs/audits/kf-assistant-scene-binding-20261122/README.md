## 工程已绑定、部件仍不动时

首轮测试中，数采读到 73、质量 192，运行页面也已加载「水平移动 ← `$$TravelInput`」，但客户端变量为 0，部件停在 X = −50。普通账号从独立实时源另读到有效点值，继续检查发现客户端工程变量已启用订阅，引用场景的页面却保存了空的 `dataSourceMng`。在独立测试工程补齐对应连接及变量 ID 的页面订阅后，又从部署实例读取页面文件确认，再打开运行标签。

助手会将已保存事件与页面订阅分别列出。遇到上述提示时，在引用该场景的客户端页面核对布局事件和工程变量，重新保存页面，再检查页面订阅是否出现。更新测试 App 并重新打开运行页后，重新取两档观察。两档值都被限幅到同一位置、镜头变化、点质量异常或取不到可见部件时，无法确认位移。

## 覆盖与复测

- 保存层可列出同一工程中实际读到的页面布局、部件 Tag、表达式事件、启用状态和变量。一次最多读取 96 个页面。未命名画布、重复 Tag、多选、路径冲突和重复绑定分别保留核对提示。
- 运行层按客户端、实时源和采集实例核验权限，每次观察用画面之前和之后的两次稳定采样夹住浏览器读数。当前自动比对范围是直接绑定工程变量的正向线性位移，本轮实机验证水平移动。不同属性、未覆盖的局部变量、脚本动画及其他数据源需分别验证。
- 现场开发和运行浏览器均使用普通账号。OpenCode 在原对话副本上用本机测试模型完成工具调用，已核对实名明细留在本机。参与者的人工复验可直接从原对话继续。

维护者在完整工作区根目录使用 Node 24 运行回归。以下脚本读取现有 M6 测试口令文件，支持用 KF_M6_PASSWORD_FILE 更改其位置。现场取证脚本限本案例专用模拟器，KF_M6_CALC_SIM_INPUT 指向其原值为 23 的输入文件；KF_SCENE_QA_DIR 为截图输出目录。KF_SCENE_QA_PROFILE 是独立的 Chromium 用户数据目录。

| 程序 | 用途 |

| check-field.mjs | 独立预览使用 5187；指定 --pilot 使用 5179。两档采样、可见几何、其他选区排除、原对话跨工程回读及历史完整性。 |
| check-ui.mjs | 从开发中心点选真实部件。使用 --pilot --capture --require-receipt 时，真实关联 Chrome 扩展并点击助手的两次采集按钮，会给试点原对话增加一条回执。 |
| check-chat.mjs | KF_SCENE_REPLAY_DB 指向试点 SQLite；程序在临时副本上发起自由提问，通过本机测试模型和真实 OpenCode 核验工具调用、证据回填与脱敏。 |
