# 独立公式执行的当前候选版

冻结版本 `c620fa7b3e38`，开发回归 183/183，试点回归 56/56。M6 本机试点仍运行 `67089443fe25`。

确认后，条件设计器只给合成输入、初值、故障与覆盖条款。两份参考程序分别根据已确认条款生成并在独立 QuickJS 实例逐项执行。各自的修订只接收自己的程序和诊断。参考宿主可观察一次或多次模拟赋值及其顺序，并对指定目标注入写异常；计算候选 JS 使用独立的 KF 脚本宿主模拟。只有两份参考执行结果一致，才形成候选校验所用的固定预期。比较失败时提供样本输入、预期与实际回包和写入；参考程序本身尚未通过时仅报告可核实的公式结果或契约错误。业务条件、参考正文及逐项执行还原记录留在本机。

新修订直接提供工程确认条款中的 InParam 字段路径。InParam 与 input 都指向同一业务对象。输入多包一层时给出明确的访问路径诊断。绑定元数据对外统一为 canRead、canWrite；模拟写入通过 write(value) 观察。业务显式声明名为 InParam 的嵌套字段时按原约定读取。
