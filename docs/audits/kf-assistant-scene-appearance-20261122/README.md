# 在 3D 场景核对旋转角度和画刷颜色

## 用原对话验收

用原普通开发账号登录[本机 M6](http://127.0.0.1:5179/)，打开「园区能源总览 → 第一段对话」。可以直接问“Rotor 和 Lamp 分别绑定了什么规则？把两档实时点值、实际角度、材质色和画面颜色列出来。”两份已记录的观察可以从园区能源客户端入口读回。

若要从对象核对，在「客户端管理 → 测试工程-8」中进入 **测试工程-37 → 3D资源管理**，双击 **SignalBench**。原生编辑器在新标签打开。如果显示未命名画布，双击左侧场景列表中的 SignalBench 缩略图。

1. 单击左侧长条 **Rotor**，打开开发助手，在原对话选择「工程工具 → 三维部件绑定回读 → 查询」。确认 Tag 为 `rotor-signal`，布局为 `SignalLayout`，属性为「z轴旋转」。
2. 单击右侧方块 **Lamp**，同样查询。确认 Tag 为 `lamp-signal`，属性为「画刷」。两者读取 `$$TravelInput`，客户端变量经 `MotionRt` 映射到设备 `TravelBench` 的 `BenchInput`。订阅关系保存在引用场景的页面 `EnergyStatementView`。
3. 要采集新结果，用同一普通账号登录[运行客户端](http://192.0.2.1:23652/)。让目标部件中心可见，单击 Chrome 工具栏「KF 运行画面核对」，确认扩展显示 KF。已有旧版解压扩展时，在扩展管理页点一次重新加载，再关联标签。扩展目录
4. 回到当前部件的工程工具，在第一档点值稳定时点「记录第一次画面」。切换模拟输入，保持页面、镜头和照明不变，待第二档稳定后点「记录第二次画面」。对另一个部件重复操作。日常回读已存结果无需操作模拟器。

## 已保存规则和 M6 运行回执

## 支持范围与复测

线性轴旋转支持原生 X/Y/Z 轴规则，此轮现场验证 Z 轴。圆形或对称部件实际轴角虽变，但如果观察不到轮廓变化，助手会保留差异结论。纯色画刷支持有序数值比较，只有运行材质和中心渲染像素均符合时才判定一致。无条件命中、无有效采样、被遮挡或两档同色时无法确认颜色变化。自旋转速度、纹理、渐变、闪烁和脚本动画另行验收。

- 普通账号 UI 实测在完整工作区根目录用 Node 24 运行。隔离验收入口使用 4175，传入 `--pilot` 切到 5179。在试点运行会给同段对话增加两份回执。指定 `KF_SCENE_QA_DIR` 作为截图目录，`KF_M6_CALC_SIM_INPUT` 指向独立模拟器当前值为 23 的输入文件。`KF_SCENE_UI_PROFILE` 可指定独立浏览器配置目录。
- 回执回读检查读取客户端入口、两个独立选区和此前的位移回执。`--pilot` 使用实际试点。
- OpenCode 回放使用 `--appearance` 和 `KF_SCENE_REPLAY_DB` 在对话副本上核对工具调用及本机证据填入。本轮回放使用本机测试模型，未向云端发送现场数据。
